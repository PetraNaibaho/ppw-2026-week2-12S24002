# Portofolio Profil Profesional - Petra Ignatius Pengayoman Naibaho

Repositori ini berisi halaman web portofolio profil profesional tunggal (*Single Page Showcase Webpage*) yang dibangun untuk memenuhi Tugas Mandiri Mata Kuliah Pengembangan Pembagian Web.

## Feature Utama
- **Struktur Semantik HTML5**: Menggunakan `<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, dan `<footer>`.
- **Data Tabular & List**: Rekapitulasi prestasi dan kepanitiaan disajikan dengan `<table>` semantik lengkap serta kombinasi HTML Lists (`<ul>` dan `<ol>`).
- **Formulir Interaktif & Accessible**: Menggunakan `<fieldset>`, `<legend>`, pasangan `<label for>`, serta atribut validasi `required`.
- **CSS Modern & Responsif**: Menggunakan palet warna 60-30-10, CSS Grid, Flexbox, serta Media Queries untuk tampilan mobile.
